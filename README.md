# RelocateSmart (Bharat Civic & Commute Intelligence)

> **A strictly law-compliant Commute & Civic Intelligence Engine for Indian job seekers relocating across Tier-1, Tier-2, and Tier-3 urban hubs.**

---

## 🎯 Executive Summary & Strategic Pivot

Rather than building a real estate listing site (which triggers **RERA §9** broker licensing and **Consumer Protection Act** liability) or an open review forum (which invites criminal defamation charges under **Bharatiya Nyaya Sanhita (BNS) §356**), RelocateSmart operates as a **Smart Commute & Civic Intelligence Aggregator**.

It solves the primary question of relocating job seekers:
> *"Given my office location and budget, which macro-zones will allow me to reach work on time during 9:00 AM rush hour, stay within 3 km of a trauma hospital, and avoid chronic civic failures—backed strictly by verifiable public data?"*

---

## ⚖️ Indian Legal Safeguards Built-In

1. **Countering "Paid PR" Legally (BNS §356 / IPC 499 Defense):**
   - No subjective "Good / Bad" judgments.
   - Shows the **PR-to-Ground-Reality Divergence Ratio** by juxtaposing marketing press releases against municipal open complaint dockets (e.g., OpenCity, VMCL, BBMP Sahaaya).
   - Every score line item includes a clickable, verifiable public source link.
2. **Citation-Required Alert Model (BNS §353 & §196 Defense):**
   - The platform strictly bans unverified "rumors".
   - Users can only log civic alerts if accompanied by an official ticket ID (Municipal, CPGRAMS, Police Advisory, or news link).
3. **Institutional Contact Directory (DPDP Act 2023 & IT Act §66E):**
   - Personal mobile numbers of Ministers, MLAs, MPs, and Police Inspectors are omitted.
   - Only published institutional landlines (Thana reception, 112 Control Room) and official e-Office emails are cataloged.
4. **Draft & Redirect Grievance Gateway (IT Act §66F / §43):**
   - Platform never spams ministry servers.
   - It pre-fills standardized citizen representations and deep-links users directly to **CPGRAMS** (`pgportal.gov.in`) or State Portals (*Digital Gujarat*, *CM Helpline MP*, *e-Janaspandana*, *Aaple Sarkar*).
5. **Macro-Zone Recommendations Only (RERA §9 & Consumer Protection):**
   - Recommends macro-neighborhoods (e.g., *Manjalpur, Vadodara* or *Dewas Road, Ujjain*), never specific builder projects or landlords.
6. **Intermediary Safe Harbor (IT Rules 2021, Rule 3):**
   - Prominently displays the India-based Grievance Redressal Officer (GRO) contact details, 24h acknowledgement, and 36h takedown protocol.

## 🚀 Quickstart

### Prerequisites
- Node.js (v18+)
- npm (v9+)

### Installation & Run
```bash
# Clone or navigate to the directory
cd RelocateSmart

# Install dependencies (already completed)
npm install

# Start development server
npm run dev

# Or build for production
npm run build
npm run preview
```
